# 泡泡焦：光学核与共享虚化管线

## 范围与实现状态

用户要求泡泡光斑由光学原理形成，并明确允许其余虚化算法参考和复用已有实现。因此，生产入口仍为 `OglBokehProcessor.applyBokeh`：复用深度极性解析、U2NetP 主体保护、RGB 引导的分层深度、预乘颜色重建、工作分辨率渲染、原分辨率输出。仅 BUBBLE 使用独立计算的光学 PSF，DEFAULT / NATURAL 保持原风格路径。持久化名称不变。

**主体保护和高光/背景分离是计算摄影的合成选择；两个光斑核分别是声明的虚拟镜头的几何光学结果。** 整张输出不能宣称来自同一枚真实镜头或精确的逐瞳孔遮挡积分。主体开启保护时，其清晰度来自共享的主体合成，而不是声称有强球差的镜头在合焦处仍然无像差。

旧泡泡焦的拟合亮边、高光增益、尺寸修正及独立逐瞳孔渲染器已删除。生产目录只保留 OpticalLensProfile、OpticalSceneCalibration、OpticalPsfTable 和 OpticalColorTransfer，以及共享管线使用的 PhysicalBokehShaders。PupilPropagator / OpticalFourierTransform 已移到 src/test，仅作为数值测试基准，不随应用打包。当前生产 PSF 采用几何近似，尚不模拟衍射、光谱色差、镜筒口径蚀、场依赖像差。

## 1. 弥散圆为什么形成

理想近轴透镜满足 `1/f = 1/z + 1/v`。传感器固定于对焦距离 `z_f` 的像面 `v_f` 时，其他物距的光束未在传感器上收束到一点，传感器截得一个光锥截面。入瞳半径 `a=f/(2N)` 时，其几何半径为：

```
c = a |1 - v_f/v(z)| = a v_f |1/z - 1/z_f|
```

除以像素间距 `p` 得到像素半径。均匀透射的理想圆孔在大离焦极限下产生均匀实心盘，**理想圆孔本身不会自动产生亮边**。光源不是数学点时，其成像是光源形状与 PSF 的积分，宽亮片和已经虚化的亮点会填平光斑中心。

波动光学以复瞳函数 `P = T exp(i 2πW/λ)` 定义像面振幅，PSF 为传播后振幅的模平方。不同非相干光源的强度相加。基础关系可核对 [爱丁堡大学 Operation of a Simple Lens](https://www2.ph.ed.ac.uk/~wjh/teaching/mo/psf.pdf)，本文的瞳面模型、符号、数值核与工程实现独立建立，不参考现有泡泡焦实现。

## 2. 从瞳面光程到亮环

采用理想近轴聚焦系统与固定径向薄相位元件，残余光程为偶次幂：

```
a = f/(2N)
S = c_n a^n
W(ρ, Δq) = [a² Δq/2 + D_focus] ρ² + S ρ^n
0 ≤ ρ ≤ 1,  Δq = 1/z - 1/z_f
```

`c_n` 固定，收光圈只改变被使用的实际瞳孔范围。这可对应厚度变化为 `r^n` 的薄折射相位片，不把参数解释为参考照片某支真实镜头的反求处方。

几何光线横向位移由光程梯度确定。以带符号的径向像素坐标表示：

```
r(ρ) = v/(a p) ∂W/∂ρ = Aρ + Bρ^(n-1)
A = (a v/p) Δq + A0
A0 = 2v D_focus/(a p)
B = n v S/(a p)
```

最小化均匀瞳孔下的几何 RMS 光线半径 `∫r(ρ)² 2ρ dρ`，得到：

```
A0 = -4B/(n+2)
D_focus = -2nS/(n+2)
```

这定义每次调整光圈后的几何最佳焦点；它不等同于最佳 Strehl 焦点。改变球差必须同时改变合焦核、焦前核、焦后核，不能只改背景环宽。

均匀瞳孔中 `dE = 2ρ dρ`。映射到半径 `R=|r|` 的像面环带 `dArea=2πR dR` 后，各个原像分支的面积密度相加：

```
PSF(R) = Σ ρ / [π R |dr/dρ|]
```

当 `dr/dρ = A+(n-1)Bρ^(n-2)` 接近零，宽瞳孔环带被压缩到窄像面环带，形成焦散和亮边。穿轴光线保留能量，在相反方位到达 `|r|`，不能裁成零半径。焦前与焦后的 `A` 符号不同，PSF 因而不对称。

几何焦散处公式会发散，所以程序不直接除零或截断峰值，而将有限瞳孔面积投到有限像面环带；每个环带存真实光能和面积。波动传播及像素面积在现实中也会限制无限峰值。

## 3. 参考图与参数选择

参考图可见：局部亮点具有较亮边缘和非零内部；高光重叠自然相加；较大亮区不应自动拆成小圆；主体清晰；部分离轴光斑略有形变。当前模型覆盖径向明暗、尺寸、有限光源、叠加及焦前后差异，未实现离轴猫眼与色边，不能用任意椭圆或 RGB 偏移冒充这些光学现象。

报告问题的猫照片本身已经具有较宽背景亮点。在 `4096` 长边、`f/1.8`、焦点视差 `.33435`、背景视差 `.06` 下，旧 75 mm 配置的支持半径约 22 px，与原图亮点宽度接近，额外卷积后很难保留亮环。

普通背景的固定虚拟镜头选择 `phase-plate-135mm-order4-balanced`：

| 参数 | 数值 |
| --- | --- |
| 焦距 / 虚拟像面长边 | 135 mm / 36 mm |
| 名义对焦距离 | 2 m |
| 参考光圈 | f/1.8 |
| 径向光程阶数 | 4 |
| 参考瞳孔边缘残余光程 S | 5.6915283203125 μm |
| 4096 长边参考 A0 / B | −6.6667 px / 10 px |
| 逆物距差到像素的系数 | 617.6944 px / m⁻¹ |

归一化视差通过共享 BokehDefocusModel 标定为带符号的基础离焦半径 C，再由 Δq=C/(av/p) 得到光程中的二次离焦项。它复用自然、旋焦的焦点死区、归一化深度跨度和计算光圈响应；不是实测米制深度，也不是固定的 .5 m⁻¹/disparity。焦点与计算光圈的界面标定会影响这个虚拟 Δq，不能将其宣称为固定真实场景的逆距离。三种风格使用相同基础离焦量，泡泡的球差能量由固定相位片另行决定。

对背景视差 `.06`、焦点 `.33435`、4096 长边及 f/1.8，共享基础离焦半径为 38.8075 px，普通背景 PSF 支持半径为 35.4742 px（此前 71.5549 px）。四阶模型在最小 RMS 焦点附近满足 RMS²=C²/2+B²/36，基础离焦与残余球差不再通过一个风格独有的全局深度比例混在一起。对 σ=8 px 的紧凑光源仍可保留亮环；σ=16 px 的宽光源在这个较小尺度下可能无明显亮环，因此局部高光能量进入下面声明的独立传播路径。

该镜头在 f/1.8 合焦 E80 半径约 2.07 px、支持半径 3.33 px（4096 长边）。收放光圈仍按实际瞳孔改变固定相位片的球差，不能保证不同核的视觉锐度完全相同。共享 CoC 决定焦点附近的原图合成权重，PSF 支持半径只负责积分范围；不能把含残余球差的支持半径用作离焦强度。参考图无法唯一确定镜头、绝对深度或丢失的 HDR 信息。

### 大尺度高光与当前背景强度共存

同一深度的一枚真实线性镜头不能只给亮点一个大 PSF、同时给其余纹理一个小 PSF。为满足保留当前背景强度且恢复大泡泡的目标，显式采用双路径计算摄影：

```
L = 预乘背景线性 RGB
E = 受局部背景、亮点证据、离焦和覆盖率限制的正高光能量，0 ≤ E ≤ L
R = L - E
E_remaining = E 中未被可靠识别为紧凑光源的部分
F_i = 第 i 个已识别光斑的线性 RGB 积分
输出背景 = Gather(K_background, R) + Gather(K_emitter, E_remaining)
         + Σ F_i K_emitter(x - center_i, depth_i)
```

两个 gather 输入均保留原有效覆盖率作为归一化支持，不能把 E 的亮度当作 alpha，否则求积会重新放大稀疏高光。R 在 gather 内用相同坐标、相同 LOD 从 L 扣除完整 E；mipmap 的线性使这一步保持分解关系。已识别像素从 E_remaining 中移除，其 RGB 积分只进入新光源一次。两个 PSF 行都具有单位能量，不复制光源、不补 HDR、不附加峰值增益。

`OpticalEmitterReconstruction` 在工作分辨率上识别已有光斑：轻度平滑仅用于寻找局部峰值，沿亮度上升方向划分相邻光源；颜色积分始终读取未经平滑的 E。以亮度加权质心定位，协方差、区域填充率、尺寸、深度一致性和画框完整性判定紧凑性。目标 PSF 支持半径必须大于观测等效半径的 1.2 倍，才接收重建。所有权掩码与光通量积分使用同一批像素，拒绝的候选保持原路径。

这一步假设可靠的紧凑亮斑是已经经过相机 PSF 的未分辨光源，从而避免把旧光斑再次与新 PSF 卷积、填平亮环。它是受约束的光源估计，无法从单张照片唯一恢复真实光源；较大亮面及无法可靠识别的部分继续保留有限形状。新光斑由瞳面 PSF 决定，观测半径只用于分类，不用来拟合圆环。

局部背景用深度/覆盖率约束的灰度开运算估计（先腐蚀、后膨胀，中心及两圈共 33 个采样点，外半径为图像长边 / 65）。该估计将相邻亮点与延展亮面分开，正差形成高光候选。亮点证据同时检查邻域，以保留有限光源较暗的外围，否则留下的外围会在小 PSF 下填平大环的中心。亮度采用线性 RGB 最大通道，证据的平滑区间为 .16–.5；这些是计算摄影分类参数，不是光学定律。仅焦后、充分离焦且背景覆盖完整的源像素可进入 E；所有光线仍按源深度计算。

高光镜头 `phase-plate-200mm-emitter` 使用 200 mm 焦距、36 mm 虚拟像面、2 m 名义对焦距离、f/1.8 参考孔径和 22.76611328125 μm 四阶边缘光程。它读取 **135 mm 背景标定得到的同一个 Δq**；如果再次按 200 mm 反算 Δq，会把大光斑又压回普通背景尺度。光线位移仍由 `v/(ap) ∂W/∂ρ` 计算，源像素中心保留在共同图像坐标中。这是两套已配准 PSF 的合成，不是改变真实相机焦距却声称视角不变。

上述示例深度下，高光支持半径约 75 px，背景仍约 35 px。高光尺度变化来自另一套明确的虚拟光学参数，不来自形成后的圆环半径缩放。高光周围的局部结构和对比会随能量传播改变，不能声称整张照片的感知虚化完全不变。

## 4. 光学 PSF 表

`OpticalPsfTable` 每次根据镜头、光圈、焦点和输出尺寸构建：

1. 257 个视差节点覆盖 `[0,1]`。每个节点使用 16,384 个等面积瞳孔中点 `ρ=sqrt((i+.5)/M)`。
2. 对所有光线计算 `|Aρ+Bρ^(n-1)|`，累计到等宽像面环带；每环密度等于光能除以 `π(r_outer²-r_inner²)`。
3. 环带宽度为 `max(0.5 输出像素, 0.25 工作像素)`。表边界包括端点和内部驻点，绝不只用边缘光线估算支持范围。
4. 每一行严格累计全部瞳孔样本，因此总质量为 1。两深度行线性插值仍保持单位总质量。
5. 上传累计能量 CDF 和支持半径为 `R32F`，使用 nearest sampler。环带内 CDF 按半径平方插值，不能让普通线性过滤改变面积积分。
6. 对一个有限径向采样区间，以 CDF 差除以环带面积计算平均密度，避免直接采样奇异峰。径向区间由工作像素宽度确定，不随远处稀疏采样而任意增宽。

CDF 区间平均是几何核的数值滤波，不能宣称等价于精确二维方形像素积分。生产图片还受深度插值、图像过滤和有限空间求积影响；CPU 表的单位质量不等于整张分层照片严格保光通量。

## 5. 复用的生产管线

```
输入原图 + 已解析极性的深度 + U2NetP 蒙版
  → RGB 引导上采样与分层细化
  → 预乘背景线性颜色 / 有效覆盖率
  → 局部背景估计与正高光能量分离
  → 紧凑光斑识别、中心与线性 RGB 积分、剩余高光纹理
  → 普通背景残差与剩余高光分别由瞳面 PSF 表驱动积分（最长边 1280）
  → 已识别光源通过实例化四边形绘制同一物理 PSF
  → 在线性空间相加
  → 原分辨率主体覆盖合成、源色彩空间编码
  → Bitmap 输出、保存及缩略图
```

分层深度使用共享契约：`R=可见深度，G=主体深度，B=补集深度，A=主体覆盖率`。颜色在去除输入传递函数后才与覆盖率相乘，避免主体颜色提前混入背景。采用 `OpticalColorTransfer` 对真实输入 RGB 色彩空间解码/编码，保留原色与 RGBA_F16 输出，非参数化传递函数会明确拒绝。

两条路径复用 `PhysicalBokehShaders.gather`，各使用 512 次空间求积：384 点覆盖目标像素的局部光斑支持圆，128 点覆盖全局支持圆。两个提议分布的混合密度为：

```
q(x) = 0.75/(π R_local²) × 1[|x|≤R_local]
     + 0.25/(π R_global²) × 1[|x|≤R_global]
weight = PSF_sourceDepth(|x|) / q(x)
```

这样在当前背景的有效范围内分配更多样本，同时仍允许其他深度的散焦光线进入。光学权重取**源像素深度**，不是简单按目标像素挑一个模糊半径。纹理 LOD 根据求积密度确定源面积，禁止随离中心距离增加而直接抹宽亮点。

沿用共享分层的深度可见性规则和预乘支持归一化；它们是计算摄影的遮挡近似，不是逐瞳孔精确可见性。整块保护主体直接保留原图，边缘按共享覆盖率合成。没有可用背景支持时保留原像素，不凭空制造隐藏内容。

画框外颜色未知，生产求积同时排除越界颜色与其支持权重；不把图像边缘无限复制到一个光斑，也不引入另一颜色的远平面。此处是有声明的有限视野边界条件，无法恢复真实画框外光源。

一般风格仍使用原有工作分辨率和 PSF。BUBBLE 的背景最长边为 1280，输出、主体细节与像素尺寸仍为原分辨率；这会限制背景最窄光斑的空间分辨率。

## 6. 性能、取消与所有权

旧生产路径每个 tile 重画数百次 RGB-D 网格，用户日志为 88 tile、平均 593.45 个瞳孔样本、9 个 tile 到 1024 仍未达到变化阈值，耗时 14.319 s。继续加样本既不能解决原图亮点尺寸，也无法满足交互速度。

主路径包含两份 PSF 表、两次共享 gather 和三个高光背景估计/分离 draw。光源重建读回工作分辨率 RGBA16F 高光和深度，CPU 识别后上传剩余纹理与实例数据；无亮点证据时跳过深度读回和区域分析。已识别光源通过一次实例化 draw 在线性 RGBA16F 目标上相加，alpha 不累加。读回会引入 GPU 同步成本，日志单独报告光源数量、所有权像素数与重建耗时。逐瞳孔 RGB-D 渲染器、分块支持范围计算、独立 EGL/FBO、累计误差归约 shader 和旧采样器已移除，正常处理不再包含这些资源与收敛日志。

取消从 ViewModel 传递到深度准备、PSF 表生成和 GPU pass 之间。已提交的 GPU draw 不能中途撤销，取消检查在结果保存前阻止旧结果继续写入。ViewModel 的图片/文件作业使用互斥锁串行所有权，避免快速连续调整或关闭虚化时发生旧作业覆盖新文件。临时 Bitmap 在 finally 释放。生成后的虚化图用于缩略图，关闭虚化恢复原图缩略图。

## 7. 验证与局限

Kotlin 编译、光学及测试目录内的 Fourier 数值测试、PSF 表的质量/支持/CDF/有限光源测试、当前光学及默认/自然风格 shader 变体的 NDK 编译均有独立检查。GLES 遵守 [驱动兼容性手册](gles-driver-compatibility.md)，并使用独立 `app_process` 执行生产 Kotlin/GLES，无 APK 安装卸载、无 Android Test。

真实照片诊断复用原始 `4096×3072` JPEG、`518×518` 浮点深度以及应用原有 U2NetP `320×320` 模型/推理实现。诊断仅替代日志和 direct-buffer 分配工具，不替代光学、shader、深度或合成逻辑。模型推理、图片虚化、最终 JPEG 保存和图库刷新应分别计时，不能用单独 shader 时间冒充端到端交互时间。

最终设备测量与验收结果记录于本节后续条目。几何 PSF 的径向对称、虚拟深度、分层遮挡近似及输入原有模糊仍然是明确边界；高光分类只选择被重新传播的输入能量，不决定亮环形状，不通过拟合描边或增益掩盖光学限制。

### 统一强度前的设备结果（历史记录，2026-09-10）

### 三风格强度标定统一

生产 CPU 和 GLSL 共用 `BokehDefocusModel`：

```
gap = max(abs(depth-focus)-.015, 0)
span = max(max(focus,1-focus)-.015, .15)
normalizedGap = clamp(gap/span, 0, 1)
apertureScale = min(1.4/max(N,.7), 1.25)
C = sign(depth-focus) × imageLongEdge/26
    × clamp(normalizedGap^1.25 × apertureScale, 0, 1)
```

`uBaseCocRadius` 表示基础强度，`uMaxBlurRadius` 表示当前算法需要搜索的范围，二者分开绑定。自然/旋焦的强度曲线保留，尺寸基准统一为图像长边，竖图不再因为使用宽度而弱于同尺寸横图。泡泡光斑由共同 C 校准入射波前后进行瞳孔传播，没有对形成后的光斑做半径压缩、峰值增益或按亮度调尺寸。

# MGC 降噪强度链路数学审计

本文审计的链路：多帧合成 → 输出噪声模型 → 经 demosaic、白平衡、RGB→YUV 的噪声传播 → 强度图 → 降噪阈值。审计逐段从第一性原理推导应有的方差，与实现做对比，非平凡的地方用 Poisson-Gaussian 合成 RAW 做蒙特卡洛核对。

记号：x 为归一化信号 (raw − black)/(white − black)，单帧方差 Var = S·x + O（Camera2/DNG 约定）。降噪阈值方差 ∝ strength² × 模型方差，所以模型方差误差 k 倍，等价于各层 strength 放大 √k 倍。

## 已验证正确

- **逐帧曝光换算。** 帧信号为 y = k·x 时，Var = k²O + kS·y。read 乘 k²、shot 乘 k 正确；Bayer 路径 shot 乘 (wb·k)、read 乘 (wb·k)² 也正确。Bento 短帧使用各自帧的模型。
- **输出曝光归一化。** read 乘 s²、shot 乘 s；SNR 对 s 不变，代码用 `referenceSignal·s`，与之一致。
- **Sabre 合成代数。** 参考帧权重 1/N，其余帧各 1/N，Σw²/(Σw)² = 1/N。
- **Savannah 相关谱。** 归一到均值 1，总方差仍由 read/shot 承载；可分离 2D 约定与 `PrepareDefaultBayer` 的 mean²、金字塔传播的 energy² 一致。
- **防重复计数。** 输出模型 frameCount 置 1，prepared 谱优先于合成谱，strength map 只用一次，单帧使用恒等模型。
- **校准器统计量。** 128×128 共 16384 个样本，方差的相对标准差约 1–2%；luma shot 拟合是线性的。
- **合成权重。** 合并与强度图 AOT 使用同一组 frameWeights / kernelSigmas，输入一致。

## 真机实测结论

测试设备为 Adreno 840，ISO 7100、3 帧 Sabre。

### F1：Scale(2)：属于 MGC 调参约定，保留

模型按 x' = 2·wb·x 缩放（read ×4、shot ×2），而打包像素是 q = 16383·wb·x。

- **实测：** 给 RawToYuv 输入平场 q=2949，输出 Y 均值 2949.00，yGain=1.0000。像素确实在 Q14 域，所以喂给降噪器的方差在物理上是 read ×4、shot ×2。
- **为什么不算缺陷：** Scale(2) 与 Q14 打包（RawToYuv 白点 16383）来自同一次 MGC FinishRaw 移植，MGC 原版就是这个组合。luma/chroma 强度曲线里的 strength 是"相对 Scale(2) 模型 σ"的系数，不是"相对物理 σ"的系数。
- **曾经的错误修复：** 一度把缩放改为 1。实拍降噪明显弱于预期，因为所有阈值 σ 都被压到原调参的 1/1.44～1/1.9，现已恢复。
- **结论：** 判断降噪强度对不对，要看是否与 MGC 调参约定一致，而不是看模型方差是否等于物理方差。本文其余各项的"误差"都在这个约定之内衡量。

### F6：LSC 强度乘子：实测正确，无需修改

- **实测：** 输入基础强度 Q8=256、平坦增益 g=2，`ComputeStrengthMap` 输出三个平面 [256, 512, 1024]，即 g⁰、g¹、g²。
- **解释：** 这三个平面正对应噪声多项式的三项。像素 y = g·x 时，方差 = g²·read + g·shot·y + quad·y²，所以 quadratic、shot、read 各自乘 g⁰、g¹、g²。
- **结论：** MGC 本来就是分项施加 LSC 的，审计中"单一乘子"的假设不成立。

### A1/A2：输出模型与 Q8 的分工：实测自洽，无需修改

测试条件为 ISO 7300、3 帧 Spatial RGB。

- **输出模型已含合成缩减。** `outputReadOverReferenceRead=0.306`，对应帧权方差比 Σw²/(Σw)² = 0.333，略好于 1/N，多出的部分来自插值核的平均。
- **Q8 是相对乘子，没有重复计数。** 静态区 Q8 中位数 254、均值 260，约等于 256（单位乘子），说明 map 不再乘 1/N。
- **拒绝区方向正确。** P95 为 296，最大值 1039（4.06 倍），朝单帧方差回升（期望 1/0.306 ≈ 3.27 倍），极值略高约 24%。
- **tuning SNR 自洽。** finishRawDenoiseSnr 为 5.45，refSNR·√N 为 5.22。

## 后续（较大改动）

- **F4：RGB 输入的 YUV 传播忽略通道相关。** Spatial RGB 和 Sabre 的色差插值让 corr(R,G) ≈ 0.3–0.4，独立模型下 Y 低估 1.39 倍、Cb/Cr 高估约 1.3 倍。应让合成噪声经过同一插值，测出 YUV 协方差。
- **F5：Sabre 只有全局模型 σ²·d/N。** 运动区和拒绝区方差低估 N/d（8 帧时 8–11 倍），降噪不足。应在累加器中加 Σw² 通道生成逐像素 Q8。
- **F7：校准器只测白噪声传递，缺少交叉项。** 应补上 mean(S_in⊗S_in·T)，否则 Cb/Cr 低估最多 1.4 倍。应在合成噪声场中注入输入谱。
- **合成 DNG 的 NoiseProfile 是默认降噪之前的合成模型。** 默认降噪的残差未建模，对已默认降噪的像素再调节时仍偏保守（偏强）。
- **Bento 超短帧的局部传播。** Fixed16 的 Bayer 合并输入按白黑电平与曝光归一。噪声传播仍需核对超短帧被接受时 RGB 或 Bayer 分支各自的插值核能量。

## 与原版 GCam ProcessRaw 的链路对齐

对照的是 AGC 9.6 `libgcastartup.so`，并用 MGC 9.7 V25 交叉验证。

**确认与原版一致，无需修改：**
- 色度相关谱：只有一份 128 点谱，Y/Cb/Cr 共用；Savannah 谱只由 G 通道拟合。
- 色度的 shot/quad 只取通道 0。
- Scale(2)。

**已修正的两处差异：**

1. **执行顺序。** 原版是 RawToYuv → Pecan → 把降噪后的 Y 写回 linear_yuv → ChromaDenoise，色度降噪拿到的是干净的 Y。我们原来是色度先于亮度，现已改为原版顺序。MeasureMoire 仍读 RawToYuv 输出的 Y。
2. **低频色度支路（ProcessLowFrequency）。** 原版在低分辨率上再做一遍色度降噪，我们此前没有这一级。现已在全分辨率 JNI 中补上，各步骤如下：
   - **降采样：** 对 [Pecan 降噪后的 Y, 色度降噪后的 Cb/Cr] 做 2^L 的 box 降采样，用舍入均值（0x4cc8ac8）。L 由 FinishRaw 的输出分辨率策略决定，1 倍输出时为 4 倍。
   - **噪声模型：** 降采样 L 次（0x5e99434）。频谱乘 cos²(ω/2)，抽取后归一化，read/shot/quad 统一乘 s²；白噪声时每步方差 ×1/4。
   - **色度中值滤波：** 采用 dual_3_point（ChromaDualThreePointMedianFilterS16，逐位实现）。Y 直通；U/V 分别取水平、垂直 3 点中值并平均，以阈值 1024、Q11 权重软混合。原版默认关闭，按传感器 tuning 打开，本项目选 dual_3_point。
   - **低分辨率 ChromaDenoise：** tuning 与全分辨率相同，强度图也是同一张 RAW/4 图，抽取率为 2−L，下采样因子为 L。
   - **写回全分辨率：** 低分辨率色度修正量（输出 − 输入）双线性上采样后加回全分辨率 Cb/Cr。渲染端 GuidedUpsample 只从低分辨率图像取色度，所以与原版"最终色度来自低频支路"等价，同时修正结果写进 DNG。分块（tile）调用时跳过这一级。

**未纳入：** Pecan 的 joint chroma 模式（TFLite）。我们移植的是只处理亮度的 AOT 版本，该模式在运行时是否开启也未确定。

## ISO 12700 实拍复核

样本为 OPPO Find X9 Ultra 3× 的三帧 4096×3072 BGGR RAW10，曝光时间 160909 ns。原片 DNG 的 MakerNote 记录了 Sabre 参考帧 230、参考 SNR 5.029、输出 SNR 8.944、亮度和色度强度 1.0。重放用生产 GLSL 处理中心、右侧和下方三个 1024×1024 区域，位移由同批 RAW 在各区域估计。桌面 Sabre 与实机线性 DNG 的低通亮度相关系数均大于 0.9996。手机完整的空间 LK 位移场未包含在 burst ZIP 中。

- **传感器模型。** 在低梯度、非屏幕内容的区域，用同相位帧差的 `Var(Xi−Xj)/2` 估计单帧方差，先移除局部亮度漂移。暗处和木面实测为内置校准预测的 0.94–1.03，Camera2 预测约为实测的 1.9–2.3 倍。较亮哑光平面的实测为校准预测的 0.77–0.88。保留内置校准。单组实拍无法给出跨曝光的系数拟合。
- **合成传播。** 独立噪声的加权合成方差是 `Σ(wᵢ² σᵢ²)/(Σwᵢ)²`。Spatial 绿色全局方差为单帧的 32.1%–35.4%，Q8 基图中位数 252–254、P95 283–303，中心区域的等权对照为 256。Spatial 在相对方差大于 1 时还应用 MGC 的拒帧区额外强度。Sabre 从实拍重放的拒帧权重估计的局部方差倍率中位数约 1.01、P95 1.11–1.15，局部可到 3。此估计假设各帧的插值核能量相等。Sabre 的局部噪声模型仍需计入各通道插值权重和 Resolve 的相关性。
- **镜头阴影和 CFA。** 若校正后信号为 `y=gx`，方差为 `g²O+gSy`。强度图依此分别乘 `g⁰`、`g¹` 和 `g²`。旧强度图在对齐后的图尺寸上对增益表做端点对齐，和生成像素用的坐标不同。这组素材的亮度读噪方差中位数偏低 6.7%，局部偏低 21.5%。改为按实际像素采样坐标取 4×4 单元中心，包含 Camera2 和 DNG GainMap。Spatial Bayer 同时改为按原始 CFA 相位索引 R/G/B，补齐图像边缘时保留相位。
- **MeasureMoire。** 旧代码按捕获的 CFA 元数据启用检测，Sabre 和 Spatial 传入的线性 RGB 仍携带该元数据。实拍亮平面上 79%–81% 的 Sabre 单元和 97%–98% 的 Spatial 单元被提高色度强度，P90 达 4992–7552，基础值约 256。无纹理灰场 Q14 亮度噪声 `σ=192` 时，89.9% 的单元同样触发；`σ=256` 时全部触发。V25 `ProcessRaw` 对三通道 RGB 需要单独启用位。生产入口已改用实际 RAW 输入类型判定，标准 Bayer 保留该分支，线性 RGB 跳过。

去除 RGB 的 MeasureMoire 后，六个平坦区域的亮度高频、色度高频和较低频色度残差中位数如下。数值为相同合成结果旁路降噪时的 RMS 百分比。

| 合成 | 亮度 / 色度强度 | 亮度高频 | 色度高频 | 色度较低频 |
| --- | --- | ---: | ---: | ---: |
| Sabre | 1.0 / 1.0 | 18.16% | 9.56% | 11.01% |
| Sabre | 0.85 / 0.85 | 19.15% | 9.83% | 11.70% |

在 1.0 / 1.0 下，去除误触发后，实拍绿灰边缘的低频色度投影由 50.1% 提高到 57.6%（Sabre），由 34.1% 提高到 56.5%（Spatial）。平坦区较低频色度残差分别只增加了旁路 RMS 的 0.44 和 0.11 个百分点。通用强度保留 1.0 / 1.0。对于这组素材，0.85 / 0.85 多保留少量纹理和颜色并留下略多颗粒，1.25 / 1.0 进一步减轻亮度颗粒并损失文字细节。

## Camera2、Pixel 5 与 AGC 26 号的分 SNR 调参

用同一份 ISO 12700 合成 RGB 和局部强度图，分别喂入实际捕获的 Camera2 系数、Pixel 5 和 AGC 26 号在当前相机增益下的系数。参考绿信号约 0.119，Sabre 计算出的输出 SNR 分别为 6.415、3.332、1.501，匹配镜头的校准模型为 8.944。相对匹配模型，单帧绿方差约为 1.88、7.82、41.24 倍，且倍率随信号变化。原亮度曲线的首节点在 SNR 5，Pixel 5 和 26 号都会用该行。方差增大与查表位置移动都会改变阈值。Q14 定点 shot 系数也可能饱和，因此按方差平方根估算只用于生成候选。

实拍筛选优先看六个平坦区域，逐区域比较细颗粒和较宽色斑的亮度与色度 RMS。用固定白平衡和 sRGB 显示转换估算 8 位显示码值，以匹配镜头的校准模型在 1.0／1.0 下的结果作为基准。通过每个区域和频段的门限后，再比较文字、按钮和颜色边缘。早先的 0.85／0.85 在最差区域的相对残差增加 19%（Sabre）、25%（Spatial），未通过这次筛选。

## 通用 RAWmax 曲线与第二台手机实拍验证

把噪声配置整体放大 `k` 倍会同时把模型 SNR 除以 `√k`、把滤波标准差乘以 `√k`。如果仍用这两个量直接查表，要对任意 `k` 保持同一阈值，强度函数只能正比于 SNR，阈值最终只跟亮度成正比，丢失了真实噪声信息。因此通用曲线改为基于合成像素观测，不使用设备名、镜头 ID、ISO 或配置模型名查表。选定的模型继续参与合成。FinishRaw 的观测不足或采样失败时使用原有噪声传播与曲线。

观测直接使用 FinishRaw 的 Q14 白平衡 YUV 转换。GPU 最多抽样 4096 个 8×8 块，每块用仿射去趋势的残差估计方差，邻差提供频谱形状线索。局部读数按镜头增益 `g` 和相对合成强度 `q` 还原为 `x=Y/g`、`V=Vpixel/(qg²)`。按半档亮度分箱后取低噪声分位，鲁棒拟合非负的 `O+Sx`。亮度、色度分别使用测得的噪声尺度，邻差只近似频谱。由暗侧亮度四分位计算 `x/√V(x)`，避免混合明暗场景中的亮面让阴影落入过弱的设置。

`MgcFullResolutionDenoise` 用实测 SNR 插值 Sabre 或 Spatial 原有的亮度 `binarypb`，并插值共用的色度资产。两种合成再共用一套逐层倍率，乘到资产的亮度强度、色度强度和亮度回混上。离群阈值仍取资产插值，滑杆仍乘到强度上，零值旁路对应通道。观测只输出噪声统计，原有 Q8 和镜头阴影强度图在滤波时施加一次。重放逐字节核对了双通道、仅亮度、仅色度和观测回退时的 Q8 图。

第二组素材是 OPPO A3x 5G 的 3264×2448 GRBG RAW，ISO 6400，三帧同曝光。Camera2 两个绿相位的 O 均为零，当前合成实际选用了 Pixel 8 Pro 回退。实拍逐帧差分估得绿色 O 约 `1.2–1.3×10⁻⁵`、S 约 `0.0015–0.0016`，比回退模型的 O 约 `1.4×10⁻⁴`、S 约 `0.00505` 更贴近画面。整幅 Sabre 换用回退、Pixel 5 和 26 号重合成时，旧模型 SNR 分别为 4.29、2.70、1.21，统一观测为 9.10、8.95、9.02。X9 Ultra 的同一区域换模型重合成，旧模型 SNR 为 1.50–8.94，统一观测约为 5.10–5.24。固定合成 RGB 和 Q8 后切换模型元数据，桌面生产路径输出逐像素一致。

A3x 整幅重放中，26 号的文字边缘对比度相对手机 DNG 从 41.4% 恢复到 105.2%。暗平面细颗粒的 RMS 从 DNG 的 0.59 降到 0.24 个 8 位显示码值，宽频亮度为 0.63，DNG 为 0.69。白色插头的细颗粒和宽频 RMS 均下降。平坦区域单项色度 RMS 最大增加约 0.055 个显示码值。X9 Ultra 的多区域结果继续满足平坦区优先门限，细节与纯净度存在可测折中。放大极暗样本时仍有残余，桌面重放采用估计位移，新增观测尚需在手机上复拍验证。

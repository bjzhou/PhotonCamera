# Photon Camera

[English](./README_EN.md) | [简体中文](./README_CN.md) | [日本語](./README_JA.md)

[![Google Play](https://img.shields.io/badge/Google%20Play-Get%20it%20on-green?logo=google-play&logoColor=white)](https://play.google.com/store/apps/details?id=com.hinnka.mycamera)

Photon Camera は、静止画撮影に重点を置いたオープンソースの Android カメラアプリです。
現代のミラーレスカメラに近い操作感と画質を再現することを目指しています。

## 🌟 主な機能

### 1. 高度な LUT 対応

* **複数フォーマットに対応**：`.cube`、`.png`（Halfs / Fulls）、`.xmp` プロファイルの読み込みと適用に対応しています。
* **リアルタイムプレビュー**：高性能シェーダーにより、LUT をリアルタイムで適用し、「見たまま撮れる」WYSIWYG プレビューを実現します。
* **カスタムインポート**：独自の LUT ライブラリを簡単に読み込み、自分だけの色表現を作成できます。

### 2. 高度なカラーレシピ

複数のパラメータを細かく調整できる、プロ向けのカラー調整システムです。

* **基本調整**：露出、コントラスト、ハイライト、シャドウ、彩度、色温度、色かぶり補正。
* **表現系エフェクト**：カラーエフェクト、ビネット、グレイン、フェード、銀残し。
* **プロ向けフィルター**：**HDF**（Highlight Diffusion Filter）、色収差表現、ノイズ、低解像度表現。

### 3. モーションフォト

* **独自のマルチベンダー対応**：Android の Motion Photo において、Xiaomi、Samsung、Pixel など複数メーカーへ対応するオープンソース実装を提供しています。
* **動きのある瞬間を記録**：静止画と同時に短い動画クリップを撮影できます。

### 4. 高速連写

* **フレーム数無制限**：撮影枚数に上限のない高速連写モードを搭載しています。
* **LUT 対応**：連写中でも LUT フィルターをリアルタイムで適用できます。

### 5. マルチフレーム合成 ＆ 超解像

* **画質向上**：高度なマルチフレームスタッキングにより画質を向上させます。
* **ノイズ低減**：自然なディテールを保ちながら、効果的にノイズを低減します。

### 6. 大口径ボケ表現

* **AI ベース**：ローカルで動作する **Depth Anything V2** 深度推定モデルを使用します。
* **高精度な深度推定**：被写体と背景の距離を高精度に推定し、自然なボケの遷移を実現します（継続的に改善中）。
* **オンデマンドダウンロード**：モデルは APK には同梱されません。仮想絞りを初めて有効にした際に、検証済みモデルのダウンロードが案内されます。

### 7. Phantom Mode

* **RAW 品質**：Photon Camera の LUT エンジンを適用しながら、システムカメラと直接連携して撮影します。
  一般的なサードパーティ製カメラ API で起こりやすい「画質劣化」や「過度なシャープネス」を回避します。

### 8. AI カラーシミュレーション

* **スマートスタイライズ**：**Google Nano Banana 2** 技術を利用して参照画像を解析し、元の色を復元したうえでカラープロファイルを抽出し、カスタム LUT を生成します。

## 🛠️ 技術スタック

* **UI**：Jetpack Compose
* **Camera API**：Camera2 API
* **最小 SDK**：Android 11 以降（minSdk 30）

# libultrahdr

This directory contains the source files required to build
[google/libultrahdr](https://github.com/google/libultrahdr) v1.4.0
(commit `d52a0d13814ca399fc8a07e23de1d2c63f0e8404`).

Photon links the library statically and reuses the bundled libjpeg-turbo
implementation. The upstream `LICENSE` and the licenses under
`third_party/image_io` are retained with the vendored sources.
